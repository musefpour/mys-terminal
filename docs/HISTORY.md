# تاریخچه دستورها

دستورهای کاربر به عامل، به ترتیب اجرا. پیش‌فرض زبان رابط `fa` است.

## نشست‌ها و رابط

1. ضربدر کنار دکمه Files در نوار تب برگ را بردار.
2. با جابجایی تب (کلیک یا Alt+چپ/راست) ترمینال همان تب فوکوس شود.
3. آیکن تم بوم رنگ (پالت) شود؛ آیکن اسکریپت‌ها `{}` شود.
4. سربرگ سایدبار Sessions مرتب شود: عنوان و تعداد و ضربدر در یک ردیف؛ Folder و Session برابر در ردیف بعد.
5. ترمینال کمی فاصله از بالا و پایین داشته باشد.
6. اسکرول‌بارها شبیه مک (overlay) شوند.
7. خروجی همه نشست‌ها از منوی بالا (Session → خروجی نشست‌ها). برچسب سایدبار «خروج» به‌معنی Quit است؛ برای منو استفاده نشود.
8. در حالت split فقط یک سایدبار راست برای کل پنجره؛ پنل فایل SFTP/FTP همان بدنه نشست است نه داک دوم.
9. عرض هر دو سایدبار با درگ قابل تغییر باشد و ذخیره شود.
10. منوی سه‌نقطه هر نشست روی همه چیز باز شود (پورتال به body)، نه زیر سطر خودش.
11. نوار نازک دستگیره با مثلث از هر دو سایدبار برداشته شود. بستن از ضربدر و منو باقی بماند.
12. روی هر اسکریپت دابل‌کلیک یعنی Run؛ Paste فقط دستور را می‌نویسد؛ Run دستور به‌علاوه Enter است.
13. اسپلیت‌های اضافه ضربدر بستن داشته باشند؛ وقتی فقط یک پنل مانده پنهان شود.
14. متن سایدبارها قابل انتخاب نباشد (کپشن، لیست، دکمه، عنوان). ورودی‌ها قابل انتخاب بمانند.
15. چک‌باکس‌های تنظیمات کنار برچسب تراز شوند.

## حساب و رمز

16. ورود با Google و شماره موبایل.
17. ثبت‌نام و ورود شبیه طرح Easy Gold از نظر چیدمان؛ فقط شماره موبایل (بدون کد ملی و معرف). ثبت‌نام: موبایل → OTP → رمز و تکرار. ورود: موبایل+رمز یا دکمه Google پایین.
18. رنگ لاگین و ثبت‌نام مطابق تم برنامه باشد نه کرم/طلایی.
19. رمزساز یک دکمه باشد؛ با کلیک پاپ‌آپ زیرش باز شود، رمز را نشان دهد و دکمه کپی داشته باشد.
20. رمزساز کجا است؟ (جابجا شده بود داخل ثبت‌نام و دیده نمی‌شد.)
21. ظاهر رمزساز شکیل و زیبا شود.

## پروتکل‌ها

22. AWS S3 در انواع نشست نباشد — اضافه شود.

## نگهداری عامل

23. تاریخچه دستورها در یک فایل ذخیره شود.
24. ساختار در فایل جدا ذخیره شود.
25. قوانین و مقررات هم فایل داشته باشد.

## یادداشت‌های ثابت کاربر

- پاسخ به کاربر فارسی و مثبت باشد.
- بدون مستندات ناخواسته و بدون git commit مگر درخواست صریح.
- RTL برای fa و ar؛ ترمینال و فیلد آدرس LTR بمانند.
- پدینگ چراغ‌های مک فیزیکی چپ بماند: `padding: 0 14px 0 92px`.
- Electronهای نامرتبط کشته نشوند.
- StrictMode نباشد (pty دوتایی می‌شود).
- داده ترمینال base64 نشود؛ pty در هر کلید resize نشود.
- بعد از تغییر main/preload معمولاً `npm run dev` دوباره لازم است.
